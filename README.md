# ☁️ 플랜두씨 (PlanDoSee)

**계획부터 실행, 돌아보기까지 기록하는 나만의 다이어리**

플랜두씨는 계획을 세우고, 실제로 수행한 일을 기록하며, 그 결과를 돌아볼 수 있는 웹 다이어리입니다.

단순히 할 일을 완료하는 데 그치지 않고, 예상한 시간과 실제 사용한 시간을 비교하고 다음 계획으로 개선할 점을 연결할 수 있도록 제작했습니다.

## ✨ 주요 기능

### 1. 계획 관리 (PLAN)

- 계획 제목, 시작 날짜, 종료 날짜 입력
- 계획별 성공 기준과 예상 시간 설정
- 계획 생성 및 수정
- 선택한 날짜에 해당하는 계획 표시
- 계획 수정 전후 내용을 수정 이력으로 보관
- 각 계획에 연결된 할 일 미리보기 제공

### 2. 할 일 관리 (DO)

- 계획에 연결되는 할 일 추가 및 수정
- 시작 날짜와 마감일 지정
- 예상 시간을 시간과 분으로 입력
- 우선순위(높음, 보통, 낮음)와 태그 설정
- 제목 검색, 계획별 필터, 완료 상태 필터, 태그 필터
- 우선순위 높은순을 기본으로 다양한 정렬 옵션 제공

할 일은 시작 날짜부터 마감일까지 선택한 날짜의 목록에 표시됩니다.

완료 상태는 날짜별 실행 기록을 기준으로 확인하므로, 같은 할 일도 다음 날 다시 완료할 수 있습니다. 이전 날짜의 실행 기록은 유지됩니다.

### 3. 실행 기록 관리

- 실행한 할 일 선택
- 시작 날짜·시각 및 종료 날짜·시각 입력
- 실제 소요 시간 자동 계산
- 막힌 이유 또는 메모 기록
- 할 일 완료 시 실행 기록 함께 저장
- 저장된 실행 기록 조회 및 수정
- 같은 할 일의 동일 날짜 완료 기록 중복 검사

실행 기록은 계획과 할 일 정보에 연결되며, 계획의 원래 내용을 덮어쓰지 않고 별도로 관리됩니다.

### 4. 돌아보기 (SEE)

계획과 할 일, 실행 기록을 바탕으로 수행 결과를 확인할 수 있습니다.

**집계 항목**
- 계획에 연결된 할 일 수
- 완료한 일 수
- 지연된 일 수
- 막힌 일 수
- 예상 시간과 실제 시간
- 예상 시간 대비 실제 시간의 차이

계획과 기간을 선택하여 기록을 확인할 수 있으며, 집계 숫자를 클릭하면 관련 근거 기록이 표시됩니다.

완료한 일, 지연된 일, 막힌 일 등을 선택하면 해당 할 일을 대상으로 예상 시간과 실제 시간을 비교할 수 있습니다.

또한 돌아보기 메모를 작성하고 다음 계획에 연결하여 개선 사항을 이어갈 수 있습니다.

### 5. 전체 기록 보관

계획, 할 일, 실행 기록, 돌아보기를 하나의 JSON 파일로 내보낼 수 있습니다.

내보내기 파일에는 계획 수정 이력도 포함되며, 기록을 별도로 보관하거나 확인하는 데 사용할 수 있습니다.

| `index.html` | 전체 화면 구조 및 입력 양식 |
| `style.css` | 화면 스타일 및 레이아웃 |
| `script.js` | 주요 기능과 데이터 처리 |
| `api/state.js` | 서버 데이터 조회 및 저장 |
| `contracts/pds-schema-v2.json` | 데이터 구조 정의 |

## 💾 데이터 저장

Supabase PostgreSQL을 사용하여 계획, 할 일, 실행 기록, 돌아보기 데이터를 저장합니다.

브라우저는 Vercel 서버 API를 통해 데이터를 조회하고 저장하며, 데이터베이스 연결 정보는 서버 환경 변수로 관리합니다.

서버 연결에 실패하면 기존 기록을 보호하기 위해 편집 기능을 제한합니다.

## 🚀 사용 방법

1. 배포 사이트에 접속하여 날짜를 선택합니다.
2. **새 계획 만들기**에서 계획 제목, 기간, 성공 기준을 작성합니다.
3. 계획에 연결할 할 일을 추가하고 시작 날짜, 마감일, 우선순위를 설정합니다.
4. 할 일을 수행한 뒤 완료 체크 또는 실행 기록 입력을 통해 실제 수행 시간을 저장합니다.
5. **돌아보기**에서 완료 현황과 예상·실제 시간을 비교하고 개선 사항을 기록합니다.
6. 필요한 경우 **내 자료 전체 JSON 내보내기**로 기록을 보관합니다.
